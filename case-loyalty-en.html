Loyalty program launch • Pyaterochka

1. About the project

As part of relaunching the Pyaterochka app (10M MAU), I designed the entire loyalty system: earning and spending points, the member card, the activation flow, personalized offers, and a stories format for communicating promotions. I added new features for the X5 Club program that increased average order value by 8%.

In parallel, I ran UX and A/B tests together with the UX lab and built a metrics framework based on Google HEART, and grew the product's design system with a team of four designers.
