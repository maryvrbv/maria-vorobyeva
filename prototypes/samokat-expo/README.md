# Самокат · корзина из нескольких магазинов

Живой прототип экрана «A · Корзина по времени» из тестового (Figma, файл `izG85u6C6bSeF8D3DIoXRO`, нода `2050:354`).

Что работает: степперы и пересчёт итога, переключатели, «По готовности / Всё вместе», «Ускорить» (молоко переезжает в Самокат), «Добавить в эту доставку», тост после оплаты.

## Запуск на айфоне

1. Установить Node.js 20+ и приложение Expo Go из App Store.
2. В терминале:
   ```
   cd prototypes/samokat-expo
   npm install
   npx expo start
   ```
3. Отсканировать QR-код камерой айфона. Телефон и компьютер — в одной сети Wi‑Fi; если не открывается, запустить `npx expo start --tunnel`.

## Веб-версия

`npx expo start --web` — откроется в браузере. Собрать статику: `npx expo export --platform web`.
